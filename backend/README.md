# Backend Service (Phase 3)

This directory will house the Python FastAPI backend, SQLite models, ML inference wrapper, and Web3.py blockchain client.

Planned layout:
- `app/main.py` — FastAPI entrypoint and CORS configuration
- `app/routers/` — Health, scans, dashboard, analytics, and blockchain endpoints
- `app/services/` — ML prediction loader, SQLite persistence, and Web3 anchoring
- `requirements.txt` — Python dependencies
